# ◉ ORBITA

Jeu de fusion orbitale incrémental : crée de la matière autour d'un trou noir, fusionne les corps identiques pour les faire évoluer (poussière → planète → étoile → quasar → galaxie → multivers → ∞), attrape les comètes dorées et déclenche des Big Bang pour progresser sans limite.

**Jouer :** ouvre `index.html` dans un navigateur (ou active GitHub Pages sur la branche `main`).

- Toucher : créer un corps · Maintenir : flux de matière · Glisser : lancer
- Combos, comètes bonus, découverte de nouveaux rangs, prestige infini, gains hors-ligne, sauvegarde auto.
